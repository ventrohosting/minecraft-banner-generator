# Minecraft Banner-Generator

Minecraft Banner Generator (Banner Maker): Grundfarbe und bis zu 6 Muster wählen, Vorschau ansehen und den /give-Befehl für die Java Edition 1.21 kopieren.

**Online nutzen:** [Minecraft Banner Generator](https://ventrohosting.com/tools/minecraft-banner-generator) · Demo: https://ventrohosting.github.io/minecraft-banner-generator/

## Funktionen

- Grundfarbe und bis zu sechs Muster-Ebenen wie im Spiel, mit Vorschau
- Fertiger /give-Befehl für Banner und Schild (Java Edition, Item-Komponenten)
- Befehle auf Paper 1.21.11 und 26.3 geprüft, läuft komplett im Browser

## English

Minecraft banner generator: pick a base colour and up to six pattern layers with a live preview and copy the /give command for the banner or a shield (Java Edition, item components). Runs entirely in the browser.

Use it online: https://ventrohosting.com/tools/minecraft-banner-generator

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Alles läuft im Browser, es werden keine Daten gesendet.
